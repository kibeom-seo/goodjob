# [요구사항 정의서] 02. 비기능 요구사항 및 법적/보안 컴플라이언스 명세

## 1. 비기능 성능 요구사항 (Non-Functional Requirements)

| 분류 | 세부 기준 | 측정 지표 / 목표치 |
| :--- | :--- | :--- |
| **응답 속도 (Latency)** | 공고 목록 조회 및 필터링 검색 | p95 < 200ms (Cloudflare CDN 캐시 활용) |
| **동시성 (Concurrency)** | 동시 접속자 처리 | 초당 500 RPS 이상 처리 (NestJS + Redis 캐싱) |
| **데이터 신선도 (Freshness)** | 신규 공고 수집 주기 | 최대 6시간 이내 신규 공고 플랫폼 반영 |
| **가용성 (Availability)** | 서비스 업타임 | 99.9% (단일 서버 장애 시에도 프론트/DB 분리 유지) |
| **확장성 (Scalability)** | 대용량 수집 처리 | 일일 10만 건 이상의 원시 공고 데이터 메시징 지연 1분 이내 (Kafka) |

## 2. 보안 아키텍처 및 개인정보 보호 명세

### 2.1 커뮤니티 작성자 익명성 보장 (Zero-Knowledge Anonymous Architecture)
1. **단방향 해싱(SHA-256) 적용**:
   * 작성 시점: `token = SHA-256(user_uuid + SERVER_PEPPER + daily_salt)`
   * DB의 게시글 테이블 `posts`에는 `user_id`를 외래키로 저장하지 않고 `anon_token`만 저장.
   * **보안 효과**: DB 관리자나 해커가 DB를 유출하더라도 어떤 회원이 작성했는지 수학적으로 역추적이 불가능함.
2. **IP 로그 비저장 원칙**:
   * 일반적인 시스템과 달리 커뮤니티 글/댓글 등록 트랜잭션에서는 클라이언트 원격 IP를 DB에 영구 적재하지 않음 (단, Redis sliding-window를 통해 메모리 상에서만 1분간 어뷰징 탐지 후 폐기).
3. **사용자 비밀번호 및 소셜 토큰 보안**:
   * OAuth 연동 토큰은 AES-256으로 양방향 암호화 보관.
   * 서비스 내 세션 토큰은 HttpOnly, Secure, SameSite=Strict 쿠키로만 취급.

## 3. 웹 스크래핑 법적 리스크 및 가이드라인 준수 방안

### 3.1 관련 법률 및 판례 분석
* **부정경쟁방지법 (제2조 제1호 카목/차목)**: 타인의 상당한 투자나 노력으로 만들어진 성과 등을 무단 사용하여 경제적 이익을 침해하는 행위 금지 (야놀자-여기어때, 잡코리아-사람인 판례 참조).
* **정보통신망법 (접근 권한 제한 위반)**: 보안 조치(캡차 등)를 악의적으로 뚫고 침입하는 행위 금지.
* **저작권법**: 채용 공고의 단순 사실(회사명, 모집직무, 연봉, 마감일 등)은 저작물성이 낮으나, 공고 상세 이미지 및 기획 텍스트는 보호 대상일 수 있음.

### 3.2 본 플랫폼의 법적 리스크 최소화 4대 원칙
1. **robots.txt 준수**:
   * 크롤러 구동 전 각 플랫폼의 `robots.txt`를 주기적으로 검사하여 `Disallow` 경로 크롤링을 원천 차단함.
2. **트래픽 부하 방지 (Politeness Policy)**:
   * 타깃 서버에 부하를 주지 않도록 요청 간 2~5초 랜덤 딜레이 적용.
   * 단일 IP 기준 분당 요청 수를 제한하여 서비스 거부(DoS) 오인을 방지.
3. **저작권 및 공정 이용 (Fair Use) - 뷰어 표준화 & 원본 링크 보존**:
   * 타사 채용 공고 전문을 그대로 복제하여 자사 콘텐츠인 양 호스팅하지 않음.
   * 핵심 사실 정보(팩트) 위주로 **자체 표준화 템플릿에 재가공(Transformative Use)**하여 표시.
   * 모든 공고에 **"출처: 잡코리아 / 사람인 / 리멤버 / 캐치" 원본 링크(Outlink)**를 명확히 제공하여 원저작권 플랫폼으로의 트래픽을 유도함.
4. **B2B 공식 API 파트너십 추진**:
   * 리멤버 등 공개 API 혹은 제휴 프로그램을 운영하는 플랫폼은 스크래핑 대신 정식 제휴 API를 최우선 연동.
