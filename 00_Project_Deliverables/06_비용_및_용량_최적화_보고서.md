# [비용 및 용량 부하 분석 보고서] 굿잡 (GoodJob)

## 1. 데이터 증가 시 용량 및 부하 분석
### 1) 채용 공고 데이터 용량 계산
- 1개 공고 평균 JSON 크기: 약 1.5 KB
- **1,250건 (현재 적재량)**: 약 **1.8 MB**
- **10,000건 (전국 대용량 기준)**: 약 **15 MB**
- **100,000건 (연간 누적 기준)**: 약 **150 MB**
*결론: 텍스트 기반 채용 공고는 10만 건이 쌓여도 150MB 수준으로, 현대 서버 메모리(RAM) 및 SSD 기준 0.01% 미만의 극미한 부하에 불과합니다.*

### 2) 네트워크 트래픽(Bandwidth) 비용 분석
| 인프라 구분 | 트래픽 비용 구조 | 굿잡 적용 결과 |
| :--- | :--- | :--- |
| **Vercel** | 무료 대역폭 100GB 초과 시 /100GB 과금, 상업적 무료티어 제한 | ❌ 미도입 (비용 발생 위험) |
| **AWS CloudFront** | GB당 .120 (월 1TB 초과 시 비용 발생) | ❌ 미도입 |
| **Cloudflare** | **대역폭(Egress Bandwidth) 완전 무제한  (평생 무료)** | **✅ 도입 확정 (비용 0원)** |

## 2. 최종 비용 결론
- **웹 호스팅 / 글로벌 CDN**: Cloudflare Pages & Tunnel 이용으로 **월 0원 ()**
- **데이터베이스 (SQLite / D1)**: 5GB까지 무료 제공으로 **월 0원 ()**
- **결론: 대용량 데이터가 누적되고 수십만 명의 트래픽이 유입되어도 굿잡 플랫폼의 고정 인프라 비용은 0원입니다.**
