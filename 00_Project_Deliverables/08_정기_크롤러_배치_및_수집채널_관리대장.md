## 2. 관리자 화면(/admin)에서의 채널 동적 제어 기능
관리자는 별도의 코드 수정 없이 관리자 관제 센터의 **[4. 수집 사이트 & 크롤러 주기 관리]** 탭에서 다음 작업을 수행할 수 있습니다.
1. **수집 사이트 추가**: 사이트 이름, 타겟 URL, 원하는 수집 주기(매일/6시간/실시간)를 입력하고 등록 버튼 클릭.
2. **수집 일시정지 및 재개**: 특정 채널의 점검이나 개편 시 원클릭으로 활성/일시정지 토글.
3. **수집 채널 삭제**: 대상 사이트를 목록에서 즉시 영구 삭제.
4. **수동 즉시 크롤링 트리거**: [전체 크롤러 지금 즉시 실행] 버튼을 눌러 정기 주기 외에도 실시간 데이터 수집 가능.
