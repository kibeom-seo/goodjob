## 2. 화면별 UI 상세 정의

### 2.1 [SCR-01] 메인 채용 피드 화면
* **상단 취준생 합격 응원 띠배너**:
  - `bg-gradient-to-r from-blue-600 to-indigo-600`
  - 문구: "취준생 여러분, 이미 충분히 잘하고 있어요! Good Job! 굿잡이 첫 합격을 응원합니다." (모바일 1줄 유지)
* **글로벌 헤더 (Navbar) - 1줄 컴팩트 레이아웃**:
  - 좌측: 굿잡 브랜드 로고, 서비스명, 'GoodJob' 뱃지.
  - 중앙: [스마트 채용] vs [익명 라운지 & 환승 라운지] 듀얼 탭 토글.
  - 우측 액션: [기업 무료 공고], [내 스펙 (온보딩)], [내 보관함], [로그인/프로필].
* **상단 컨트롤 및 타겟 맞춤형 고관여 필터 바**:
  - **'내 맞춤 공고만 보기' 토글 스위치**:
    - [Off (기본)]: 전체 채용 시장의 모든 공고를 자유롭게 스크롤 탐색 (구직자 탐색권 100% 보장).
    - [On]: 내 등록 스펙(기술스택/직무)과 일치하는 공고만 필터링하여 노이즈 차단.
  - **기본 정렬 분기 정책**:
    - **비회원**: `[최신등록순 (posted_at)]` 디폴트.
    - **회원**: `[AI 매칭률순 (99%~60%)]` 디폴트.
    - 3대 정렬 탭 버튼: [AI 매칭률순], [마감일순 (D-Day)], [최신등록순].
  - **스마트 검색창 & 3대 고관여 필터 칩 전면 배치**:
    - **기본 필터 칩**: `[전체]`, `[오늘 마감 🔥]`, `[마감 임박 D-7]`, `[신입환영 🐣]`
    - **개발자 타겟 고관여 필터 칩**:
      - `[풀 리모트 🏠]`: 100% 재택근무 공고만 즉시 필터링
      - `[유연근무/주4.5일 ⏰]`: 시차출퇴근제, 자율출퇴근제, 주 36시간/4.5일제 공고 필터링
      - `[병역특례 🎖️]`: 산업기능요원/전문연구요원 복무 가능 공고 필터링
* **채용공고 카드 상세 컴포넌트**:
  - **상단 배지**: [굿잡 AI 중복 정제 완료] 단일 배지 + [기업 직접 인증 (Claimed)] 황금 배지 + [D-Day 배지].
  - **기업 정보**: 고화질 이니셜 SVG 브랜드 배지, 정제된 기업명, 공고 제목, 근무 형태 뱃지.
  - **AI 매칭률 바**: 내 보유 스펙 일치율(95%) 및 부합 기술 태그 강조.
  - **굿잡 AI 공고 3줄 요약 박스 (멀티 에이전트 정제)**: [미션], [요건], [복지] 3줄.
  - **선배 현직자 꿀팁 리뷰 & 기업 공식 답변 노출**:
    - 현직자 리뷰 본문 하단에 `[기업 공식 답변] 안녕하세요, OO 기업 인사담당자입니다...` 뱃지 노출.
  - **하단 액션 바**: [스크랩], [공고 인증(Claim)], **[원문 공고 확인하고 지원하기 ↗]** (아웃링크).

### 2.2 [SCR-01-1] 개별 공고 SSR 뷰어 화면 (`/jobs/[id]`) - 동적 SEO 자동화
* **검색 엔진 오가닉 유입 전용 최적화 페이지 (마케팅 비용 Zero)**:
  - 구글/네이버 검색창에서 "토스 프론트엔드 채용", "React 신입 공고" 검색 시 굿잡의 SSR 페이지로 직접 랜딩.
  - **SEO 메타데이터**: 제목, 본문 요약, OG 이미지, `JSON-LD JobPosting` 구조화 스키마가 사전 렌더링되어 최상단 노출.
  - **페이지 구성**: 기업 로고, 공고명, AI 3줄 요약, 요구 기술스택 칩, 마감 D-Day 타임라인, [굿잡 메인 피드에서 내 매칭률 확인하기], [원문 지원하기 ↗].

### 2.3 [SCR-02] 익명 블라인드 라운지 & 커뮤니티 투명 자정 시스템
* **카테고리 탭**: [전체], [환승 라운지(주니어 적응기/실무팁)], [면접·서류 후기], [기업 비하인드], [취준 넋두리], [합격후기].
* **피드 카드 및 자동 자정 블라인드 UI**:
  - 작성자 닉네임 + 인증 배지, 경과 시간, 본문, 좋아요, 실제 댓글 수(1:1 일치).
  - 우측 상단 `[⋮]` 더보기 메뉴 내 **`[신고하기]`** 버튼.
* **블라인드 게시글 UI 분기 (투명성 & 구제 창구)**:
  1. **일반 이용자 화면**:
     - 본문이 가려진 회색 음영 박스.
     - 안내 문구: *"다수 이용자의 규정 위반 신고로 자동 블라인드(숨김) 처리된 게시글입니다."*
  2. **★ 작성자 본인 로그인 상태 화면**:
     - 주황색 경고 테두리 박스 및 본문 흐림(Blur) 노출.
     - 배너 안내: *"⚠️ 신뢰도 가중치 신고 누적으로 블라인드된 내 글입니다. 부당하게 제재당했다고 생각되시면 소명을 신청해 주세요."*
     - 우측 액션: **`[이의제기 / 소명하기]` 버튼 전면 노출** (클릭 시 `MOD-10` 팝업 호출).

### 2.4 [SCR-03] 최고 관리자 관제 센터 (`/admin`)
* **Next.js 네이티브 고성능 관제 대시보드 (AG Grid 가상화 레이아웃)**:
  1. **실시간 LIVE 접속자 & 트래픽 관제**: 실시간 동시 접속자, Cloudflare Turnstile 봇넷 차단 현황, IP 로그.
  2. **크롤러 수집 감사 로그 (Audit Trail Grid)**: 회차별 총 수집 건수, 신규 적재 건수, 중복 정제율.
  3. **크롤러 서킷 브레이커 (Circuit Breaker) 관제 탭**:
     - 7대 플랫폼별 실시간 상태 배지: `[정상 가동 (CLOSED)]` 녹색 vs `[서킷 차단: 일시 정지 (OPEN)]` 적색.
     - 파서 긴급 패치 완료 후 원클릭 **`[수집 재개 (Resume)]`** 버튼 제공.
  4. **사내 폐쇄망 경보 설정**: Mattermost / Zulip Webhook URL 등록 및 텔레그램 모바일 긴급 채널 설정.
  5. **합격 축하금 Zero-Trust 심사 큐**: ClamAV 무결성, Exif 포토샵 검증, 마이데이터 공단 직통 조회 결과 확인 후 50만 원 입금 승인.
  6. **리뷰 공식 소명 및 커뮤니티 이의제기 심사 큐**: 기업 HR의 리뷰 소명 건 및 유저의 블라인드 이의제기 건 중재 심사.

### 2.5 [SCR-04] B2B 기업 전용 ATS & 채용 분석 대시보드 (`/enterprise/ats`)
* **접근 권한**: 기업 도메인 인증을 완료한 기업 HR 계정(`role = 'ENTERPRISE'`).
* **1. 상단 채용 성과 및 퍼널 분석 KPI 위젯 (Analytics Widget)**:
  - 4대 핵심 지표 카드:
    1. `총 지원자 수`: **142명** (D+14일 누적)
    2. `평균 채용 소요 시간 (Time-to-Hire)`: **21.4일** (서류 4.2일 ➔ 면접 11.5일 ➔ 최종오퍼 5.7일)
    3. `전형 단계별 전환율 (Conversion Funnel)`: 서류합격 26.7% ➔ 면접합격 36.8% ➔ 최종오퍼 21.4%
    4. `이탈 및 노쇼율 (Drop-out Rate)`: **3.5% (5명)** (타사 최종합격 3명, 면접 노쇼 2명)
* **2. 중앙 드래그 앤 드롭 칸반 보드 (Kanban Board with Drag & Drop)**:
  - **6대 전형 컬럼 구성**:
    1. `[서류 접수 (APPLIED)]` (142명)
    2. `[서류 통과 (DOC_PASS)]` (38명)
    3. `[면접 전형 (INTERVIEW)]` (14명)
    4. `[최종 합격 (FINAL_OFFER)]` (3명)
    5. `[불합격 (REJECTED)]` (120명)
    6. **`★ [자진 포기 / 노쇼 (WITHDRAWN)]`** (5명)
  - **인터랙션 및 트랜잭션**:
    - 지원자 카드를 다른 컬럼으로 마우스 드래그 앤 드롭 이동.
    - 이동 즉시 상태 변경 사유 입력 팝오버 노출 (예: "1차 기술 면접 합격", "지원자 유선으로 타사 입사 의사 밝힘").
    - 백엔드 `PATCH /api/ats/applications/[id]/stage` 호출 ➔ `application_history` 불변 감사 원장에 즉시 기록.
  - **지원자 카드 컴포넌트 정보**:
    - 구직자 성명(마스킹: 홍*동), 목표 직무, AI 역량 매칭률(95%), 핵심 기술 스택 칩, 지원 일시, 현재 단계 체류 일수(`D+3`).

### 2.6 [MOD-08] 취준생 합격 축하금(50만 원) 신청 모달 (Zero-Trust 보안 & UX)
* **상단 2-Track 인증 방식 선택 탭**:
  - **탭 1: [간편인증으로 1초 만에 확인 (추천 ⚡)]**
    - UX 극대화: 서류 발급, 스크린샷, PDF 업로드의 번거로움 완전 제거.
    - `[카카오 인증으로 자격득실 확인]` / `[PASS 인증으로 자격득실 확인]` 버튼.
    - 클릭 시 공공 마이데이터/정부24 전산 직통 API(M2M)를 통해 1초 만에 사업장명 및 입사일 자동 대조 완료.
    - 결과 표시: *"토스증권(주) / 2026.08.01 입사 확인 완료 (진위 검증 100%)"*
  - **탭 2: [서류 직접 업로드 (PDF/JPG)]**
    - 파일 드래그 앤 드롭존: 건강보험자격득실확인서 첨부.
    - **실시간 3단계 보안 스캔 애니메이션 프로그레스 UI**:
      - 파일 첨부 즉시 모달 내부에 스캔 프로그레스 바 작동:
        - `[스캔 1/3]` ClamAV 악성코드 및 바이러스 무결성 검사 중... ➔ `[통과 ✓]`
        - `[스캔 2/3]` ExifTool 메타데이터 포토샵 변조 여부 분석 중... ➔ `[정상 원본 ✓]`
        - `[스캔 3/3]` 국민건강보험공단 직인 및 16자리 발급번호 OCR 교차 대조 중... ➔ `[일치 ✓]`
      - 완료 후 "보안 검증이 완료되었습니다!" 녹색 체크 배지 점등.
* **입사 1개월 재직 확인 안전장치 안내 배너**:
  - *"합격 축하금 50만 원은 허위 수령 및 조기 퇴사 방지(Clawback)를 위해 **입사일 기준 1개월 이상 정상 고용 유지 상태가 확인된 후** 지정 계좌로 안전하게 입금됩니다."*
* **입금 계좌 입력 필드**: 은행 선택, 계좌번호, 예금주명 확인.

### 2.7 [MOD-09] 커뮤니티 글/댓글 신고 모달 (역어뷰징 심리적 방어)
* **신고 사유 선택 라디오 버튼**:
  - 광고 / 홍보성 스팸
  - 욕설 / 비방 / 혐오 표현
  - 허위 사실 유포 및 명예훼손
  - 도배 및 부적절한 게시물
* **신뢰도 가중치 블라인드 정책 안내**:
  - *"굿잡 커뮤니티는 클린한 소통 문화를 위해 **신고자 신뢰도 가중치 합산 5.0 이상** 누적 시 해당 글을 자동 블라인드 처리합니다."*
* **⚠️ 허위/조직적 역어뷰징 방어 경고 배너**:
  - `border-amber-500 bg-amber-50 text-amber-900 p-3 rounded-lg text-xs`
  - 문구: *"⚠️ [주의] 굿잡은 조직적 담합이나 경쟁사 비방 목적의 허위 신고를 방어하기 위해 **신고자 신뢰도 평가 알고리즘**을 적용하고 있습니다. 고의적 허위 신고 적발 시 신고 권한 박탈, 계정 영구 정지 및 서비스 이용 제한 조치가 취해집니다."*

### 2.8 [MOD-10] 블라인드 게시글 이의제기/소명 모달 (정상 유저 구제 창구)
* **호출 위치**: 블라인드 처리된 본인 게시글의 `[이의제기/소명하기]` 버튼 클릭 시 호출.
* **구성 필드**:
  - 원문 글 제목 및 블라인드 일시 표시.
  - **소명 사유 입력 텍스트에리어**: 억울하게 신고당한 사유, 정당한 정보 공유 목적임을 상세 기술.
  - 증빙 자료 첨부 (선택): 캡처 이미지 등.
* **안내 문구**:
  - *"접수된 소명서는 굿잡 운영팀 검토 큐에 등록되며, 허위/조직적 신고로 판명될 경우 24시간 이내에 블라인드가 즉시 해제되고 악성 신고자에게 페널티가 부과됩니다."*
* **하단 버튼**: `[취소]` / `[소명서 제출하기]`.

### 2.9 [MOD-05] 기업 공고 소유권 인증 (Claim) 모달 (Zero Manual Operations)
* **회사 이메일 도메인 원클릭 즉시 자동 승인 UI**:
  - **회사 공식 이메일 입력**: `@company.com` 입력 시 시스템이 공고 원문의 기업 도메인과 실시간 대조.
  - **도메인 일치 시 (100% 자동 승인)**:
    - *"회사 공식 도메인이 확인되었습니다! 이메일로 발송된 6자리 인증 코드를 입력하시면 **관리자 승인 대기 없이 즉시 직접 인증 배지가 부여**됩니다."*
    - 6자리 코드 확인 즉시 `[기업 직접 인증 완료]` 황금 배지 활성화 및 공고 수정/ATS 지원자 관리 권한 즉시 부여.
  - **도메인 불일치 또는 무료 포털 메일(`@naver.com`, `@gmail.com`) 입력 시**:
    - *"공식 회사 도메인이 아닌 경우 사업자등록증 사본 첨부가 필요합니다. 서류 검토 후 24시간 이내 승인됩니다."* 안내 및 파일 업로드 폼 전환.
