# [굿잡 (GoodJob)] 상세 기능정의서 (Functional Specification)

## 1. 최우선 설계 원칙 및 기능 분류 체계

### [최우선 설계 원칙]
1. **광고 왜곡 제로 (100% 신뢰성)**: 기업의 광고비 지급 여부에 따라 공고 노출 순서나 랭킹이 왜곡되는 상업적 로직을 일체 배제하며, 오직 구직자 역량 부합도(AI 매칭률)와 최신 등록순으로 정직하게 제공합니다.
2. **데이터 무결성 1:1 보장**: 허위 댓글 카운트(하드코딩 배지 등)나 가짜 수치를 전면 금지하고, 실제 DB에 존재하는 레코드 수와 1:1로 정확히 일치시킵니다.
3. **중앙 서버 DB 기반 다중 사용자 환경**: 고립된 `localStorage`가 아닌 모든 사용자가 실시간 소통하고 공유할 수 있는 중앙 서버 데이터베이스(DB) 아키텍처를 적용합니다.
4. **수집 감사 추적성 & 장애 방어 (Audit & Circuit Breaker)**: 언제, 어느 플랫폼에서, 몇 건을 수집했고 실제 신규 공고가 몇 건 추가되었는지 100% 투명하게 기록(`crawler_run_logs`)하며, DOM 구조 변경 시 서킷 브레이커로 서버를 보호합니다.
5. **법적 컴플라이언스 & 마케팅/운영 비용 Zero화**: 아웃링크(Out-link) 지원과 SSR 동적 SEO를 통해 마케팅비 없이 오가닉 유입을 극대화하고, 유저 참여형 자동 자정 시스템으로 운영 리소스를 최소화합니다.

## 3. 세부 기능 명세 및 핵심 로직

### [F01] 채용공고 수집, 멀티 에이전트 정제, 아웃링크 및 SEO 자동화
* **F01-01 크롤러 IP 차단 방어 (Politeness Policy & Jitter)**:
  - 서킷 브레이커가 동작하기 전 대상 플랫폼 WAF/봇 탐지에 걸려 IP가 영구 차단되는 현상을 사전 방지.
  - **무작위 딜레이 (Jitter)**: 단일 주기 요청을 배제하고 `1.5초 ~ 3.5초의 난수 딜레이(Jitter)`를 주어 실제 인간 브라우징 행태 모사.
  - **헤더 순환(Header Rotation)**: 최신 Chrome/Safari User-Agent 풀 및 `Sec-CH-UA` 브라우저 핑거프린트 헤더 자동 순환.
  - **지수 백오프 & 프록시 로테이션**: HTTP 429(Rate Limit) 감지 시 지수 백오프(Exponential Backoff) 및 경량 프록시 로테이션으로 자동 우회.
* **F01-04 멀티 에이전트 AI 정제 파이프라인**:
  - **Agent 1 (스택 추출기)**: 공고 본문에서 프로그래밍 언어, 프레임워크, 라이브러리 기술스택만 정밀 추출.
  - **Agent 2 (복지/문화 추출기)**: 장비 지원, 유연근무, 복지 포인트 등 실질 복리후생 추출.
  - **Agent 3 (교차 검증기)**: Agent 1과 2의 결과물에 할루시네이션(환각)이 없는지 원문과 대조 검증 후 최종 `3줄 요약` 확정.
* **F01-06 아웃링크(Out-link) 지원 엔진**:
  - 공고 상세 카드 내 [원문 공고 확인하고 지원하기 ↗] 클릭 시 내부 저작권 침해 없이 원본 채용 사이트로 새 탭 이동.
  - 구직자의 지원 클릭 이벤트(`job_applications_outlink`)를 로깅하여 사용자 보관함 지원 현황 자동 업데이트.
* **F01-07 초기 트래픽 확보를 위한 동적 SEO & SSR 공고 뷰어 (마케팅 비용 Zero)**:
  - **개별 공고 SSR 뷰어 페이지 (`/jobs/[id]`)**: 아웃링크로 넘어가기 전 굿잡 내 'AI 3줄 요약 뷰어' 페이지를 Next.js Server-Side Rendering으로 제공.
  - **동적 사이트맵 (`sitemap.xml`) 자동화**: 매일 수집/정제된 모든 공고 URL을 동적 sitemap.xml에 자동 갱신 반영하여 Google Search Console 및 Naver 서치어드바이저에 자동 핑(Ping) 전송.
  - **OpenGraph & JSON-LD 구조화 데이터**: 구글 검색 봇이 일자리 리치 스니펫(JobPosting Schema)을 인식하도록 메타태그와 구조화 데이터를 사전 주입하여 대량의 채용 키워드가 검색 엔진 상위에 오가닉으로 노출되도록 구현.

### [F02] 탐색 및 타겟 맞춤형 고관여 필터 (F02-04)
* **개발자/IT 페르소나 맞춤 3대 킬러 필터 칩 전면 배치**:
  1. **`[풀 리모트 (100% 재택근무)]`**: 출퇴근 스트레스가 없는 전면 원격 근무 공고만 즉시 필터링.
  2. **`[유연근무 / 주 4.5일제]`**: 시차출퇴근제, 자율출퇴근제, 주 36시간/4.5일제를 시행하는 워라밸 공고 필터링.
  3. **`[병역특례 (산업기능요원/전문연)]`**: 미필 개발자 취준생의 핵심 타겟인 보충역/현역/전문연구요원 지정업체 공고 필터링.
* 상단 필터 바에 기존 칩([오늘 마감], [마감 임박], [신입환영])과 함께 전면 노출하여 타 포털 유저의 즉각적인 유입 및 락인(Lock-in) 유도.

### [F03] 원클릭 스펙 온보딩 및 컴플라이언스 파기 (F03-02, F03-04)
* **F03-02 원클릭 스펙 온보딩**:
  - 구직자가 GitHub 계정명/URL 입력 시, GitHub REST API를 호출하여 주요 사용 언어(TypeScript, Python 등) 및 Top 리포지토리 분석.
  - PDF 이력서 업로드 시, PDF 텍스트 파서 + LLM 파서를 통해 보유 스킬과 프로젝트 경험을 자동 추출하여 체크박스에 사전 채움.
  - 사용자가 잘못 파싱된 항목을 직접 수정하고 [저장]을 누르면 프로필 생성 완료.
* **F03-04 글로벌 개인정보보호(GDPR/PIPA) 및 컴플라이언스 파기**:
  - 회원 탈퇴 시 즉시 `deleted_at = CURRENT_TIMESTAMP` 기록 및 PII 난독화 마스킹.
  - 30일 유예 기간 경과 후 매일 새벽 배치 워커가 구직자의 PDF 원본 및 AI 스펙 파싱 데이터를 물리적으로 영구 파기(Hard Delete).

### [F06] 환승 라운지 및 커뮤니티 자동 자정 시스템 (F06-03, F06-04)
* **F06-03 환승 라운지**: 카테고리 필터에 `[환승 라운지]`(주니어 온보딩, 회사 적응기, 실무 꿀팁) 추가하여 취업 성공 후 지속 체류 및 후배 멘토링 유도.
* **F06-04 자동 자정(Auto-Purge) 블라인드 시스템 (운영 리소스 Zero)**:
  - 유료 AI 모니터링 API 비용 없이 유저 참여형 정화 시스템 도입.
  - 게시글 및 댓글에 [신고하기] 버튼 제공 (사유: 광고/홍보, 욕설/비방, 도배, 음란물).
  - **신고 5회 누적 시 즉각 자동 블라인드 (`is_blinded = 1`)**:
    - 목록 및 상세 뷰에서 내용이 숨겨지고 "다수의 이용자 신고로 블라인드 처리된 글입니다" 안내 박스로 대체.
    - 운영자의 24시간 수동 모니터링 없이도 불법 광고나 악성 글이 100% 자생적으로 차단됨.

### [F07] B2B 기업 마스터, Claim 자동화, 경량 ATS 및 채용 브랜딩 방어 (F07-01 ~ F07-04)
* **F07-01 기업 마스터 & 다중 HR 계정 연동 (Multi-admin)**:
  - 중앙 `companies` 테이블을 기반으로 단일 기업 아래 여러 명의 HR 담당자 계정(`users.company_id`)을 연동.
  - 법인 통합 공고 관리, 세금계산서 발행 및 채용 브랜딩(로고, 회사소개) 일괄 동기화.
* **F07-02 기업 인증(Claim) 100% 자동화 (Zero Manual Operations)**:
  - 신청 담당자의 회사 이메일 도메인(`@company.com`)이 공고 원문의 기업 공식 웹사이트 도메인과 100% 일치할 경우:
    - 6자리 이메일 인증 코드 입력 즉시 **관리자 수동 승인 대기 없이 시스템이 `is_claimed = 1`로 자동 전환**.
    - [기업 직접 인증 완료] 황금색 배지 부여 및 공고 수정/ATS 지원자 관리 권한 즉각 활성화.
    - 도메인 불일치/무료 웹메일 건만 사업자등록증 첨부 후 관리자 심사 큐(`company_claims.status = 'PENDING'`)로 분기.
* **F07-03 B2B 경량 ATS 파이프라인 및 노쇼/자진포기 추적 & 채용 분석(Analytics)**:
  - 지원자 전형 단계를 `APPLIED` ➔ `DOC_PASS` ➔ `INTERVIEW` ➔ `FINAL_OFFER` ➔ `REJECTED` 로 관리.
  - 구직자의 면접 노쇼나 타사 합격 이탈을 명확히 기록하는 **`WITHDRAWN (자진 포기/노쇼)`** 상태를 추가하여 채용 퍼널의 정확도 제고 및 리워드 수수료 청구 분쟁 원천 방어.
  - **ATS 채용 분석 대시보드 (`GET /api/ats/analytics/funnel`, `time-to-hire`)**: 서류 접수부터 최종 오퍼까지의 단계별 체류 시간(`Lead Time`) 및 전형별 전환율 실시간 시각화.
* **F07-04 채용 브랜딩 방어 & 선배 리뷰 공식 소명(Dispute)**:
  - 인증된 기업 HR 계정은 자사 공고 리뷰에 [기업 공식 답변] 코멘트 작성 권한 부여.
  - 허위 사실이나 명예훼손성 악성 리뷰에 대해 [공식 소명 신청] 접수 (`is_disputed = 1`). 관리자 검토 큐를 통해 검증 후 블라인드 처리하거나 공식 답변 병기 노출.

### [F08] 관리자 백오피스 및 크롤러 서킷 브레이커 (F08-01, F08-03, F08-04)
* **Next.js 네이티브 가상화 그리드 (AG Grid / TanStack Table)**:
  - 외부 무거운 상용 솔루션을 배제하고 React 18/Next.js 14와 100% 호환되는 AG Grid 도입.
  - 수만 건의 공고 및 실시간 IP 트래픽을 가상 렌더링(Virtualization)하여 메모리 낭비 없이 60fps로 매끄럽게 조회/정렬/필터링.
* **텔레그램 실시간 경보 봇 (F08-03)**:
  - 크롤러 오류율이 30%를 초과하거나, 트래픽 폭증/서버 에러(5xx) 감지 시 Telegram Bot API(`sendMessage`)를 통해 관리자 텔레그램 채널로 실시간 마크다운 긴급 알림 메시지 즉시 전송.
* **크롤러 서킷 브레이커 (F08-04 - 서버 과부하 및 요금 폭탄 방지)**:
  - 타 채용 포털의 웹사이트 구조(DOM) 변경 시 파서가 무한 루프 에러를 발생시켜 서버 CPU가 100%에 달하거나 클라우드 요금 폭탄이 발생하는 리스크 원천 차단.
  - **작동 규칙**:
    - 특정 플랫폼의 수집 파이프라인에서 **최근 10분 내 에러율이 30%를 초과**하거나 **연속 10회 파싱 실패** 발생 시, **해당 채널만 '일시 정지(Circuit Open / Paused)'** 상태로 자동 전환.
    - 다른 정상 채널(사람인, 원티드 등)은 정상 가동을 유지하여 전체 서비스 영향도 0%.
    - 정지 즉시 관리자 텔레그램으로 `🚨 [서킷브레이커 발동] 잡코리아 DOM 변경 의심으로 수집 일시 정지됨` 긴급 경보 발송.

### [F09] 합격 리워드 어뷰징 방어 및 채용 성공 수수료(Success Fee) 정산 (F09-02)
* **어뷰징 방어 및 3단계 문서 위변조 검증(Document Anti-Fraud Engine)**:
  - **Exif/메타데이터 검증**: 포토샵(Photoshop), Canva 등 그래픽 조작 흔적 및 레이어 수정 태그 자동 탐지.
  - **ClamAV 악성코드 검사**: PDF 악성 스크립트 첨부 즉시 격리.
  - **공공데이터 OCR 교차 검증**: 건강보험공단 직인, 16자리 발급번호, 취득 사업장명, 자격취득일을 OCR로 자동 추출하여 합격 공고/기업과 100% 일치 시에만 승인 큐 진입.
  - **1개월 고용 유지 안전장치 (Clawback 방어)**: 
    - 입사 직후 즉시 지급하지 않고, **'입사일 기준 1개월 이상 실제 정상 재직 상태'**를 확인한 후 50만 원 축하금 지급.
    - 허위 입사 청구, 단순 변심 조기 퇴사로 인한 플랫폼의 자본 손실 및 기업과의 수수료 분쟁을 100% 원천 방어.
* **기업 채용 수수료 정산**:
  - 1개월 재직이 검증된 건에 대해 기업에 채용 성공 수수료(연봉의 7% 등) 청구서 발행.
